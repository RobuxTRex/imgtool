## Responsible Disclosure
Do **not** create a public GitHub issue regarding a security vulnerability. Instead, report vulnerabilities responsibly and privately through [GitHub Security Advisories](https://github.com/RobuxTRex/imgtool/security/advisories).

We request that, upon reporting a vulnerability through appropriate channels, the vulnerability **is not exposed publicly** until the project maintainers explicitly announce it *after* a fix has been released.
